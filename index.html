📖 Complete User Guide

🎯 1. Overview

Notes Maker PRO एक browser-based tool है जिससे आप किसी भी subject के notes बना सकते हैं और PDF में download कर सकते हैं। सारा data आपके browser में automatically save होता है।

📚 2. My Notes Library

यहाँ आपके सारे notes की list दिखेगी। एक ही app में Physics, Maths, Chemistry — सब अलग-अलग notes save कर सकते हैं।

  • ➕ New Notes नया notes बनाओ (नाम दो — जैसे "Physics Notes")
  • 📗 Library Item Click करके किसी भी notes पर switch करो
  • 🗑️ Delete Notes delete करो (confirm dialog आएगा)
  • 🎨 Templates Ready-made structure load करो

📊 3. Statistics Panel

अपने notes का overview देखो:

  • Chapters — कितने chapters हैं
  • Topics — कुल कितने topics हैं
  • Pages — कितने A4 pages बनेंगे

📋 4. Notes Details

Header के लिए information भरो। जो field खाली छोड़ोगे वो paper पर show नहीं होगी।

  • Subject Name — जैसे "Physics"
  • Chapter / Unit — जैसे "Chapter 3: Motion"
  • Class — जैसे "Class 10"
  • Teacher / Author — जैसे "Ms. Sharma"
  • School — जैसे "ABC Public School"
  • Date — जैसे "06/10/2026"

📖 5. Chapters & Topics

Notes को organize करने के लिए 2-level structure:

  • ➕ Add New Chapter नया chapter बनाओ
  • ➕ Chapter header में — नया topic add करो
  • ✏️ Topic का नाम edit करो
  • 🗑️ Chapter / Topic delete करो
  • ▼ Collapse/expand
  • 🔍 Search Topic/chapter ढूंढो
  • Topic पर click करो → Content Editor खुलेगा

✏️ 6. Content Editor — 15 Block Types

Topic select करने के बाद Content Editor खुलेगा। यहाँ 15 प्रकार के content blocks add कर सकते हो:

  • H1 Main Heading
  • H2 Sub-heading
  • H3 Sub-sub-heading
  • ¶ Paragraph
  • • Bullet List
  • 1. Numbered List
  • 📖 Definition Box (blue)
  • 🧮 Formula Box (purple)
  • ⚠️ Important Box (yellow)
  • 📝 Example Box (green)
  • 💡 Note Box (gray)
  • — Divider
  • 🖼️ Image upload
  • 📊 Table
  • ∑ Math/Science Symbols

🎨 7. Design Options

  • 2-Column Auto-balanced columns — कम pages में ज़्यादा content (default ON)
  • Border Page के चारों तरफ border
  • Watermark हर page पर हल्का text (सबसे ऊपर layer में)
  • Multi Watermark एक page पर 3 watermark (top, center, bottom)
  • Watermark Text — Custom text (जैसे "CONFIDENTIAL")

📦 8. Bulk Import (Fast Method)

100+ topics के लिए text format:

  • # Chapter Name → Chapter
  • ## Topic Name → Topic
  • !def text → Definition
  • !formula text → Formula
  • !imp text → Important
  • !ex text → Example
  • !note text → Note
  • - point → Bullet
  • 1. step → Numbered
